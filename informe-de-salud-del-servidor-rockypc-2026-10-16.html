Seguridad y conexiones

  • Hay un único miembro de sysadmin: RockyPC\k_a_f. La cantidad es razonable, pero debe auditarse que la cuenta no sea personal compartida y aplicar mínimo privilegio mediante roles específicos.
  • Las sesiones 75, 74, 72, 59 y 101 aparecen cifradas mediante Shared memory. Las sesiones 109, 100, 98, 52 y 51 aparecen no cifradas, también mediante Shared memory y localmente. Se consideran riesgo mínimo en este contexto; la prioridad es asegurar conexiones TCP remotas con certificado y Encrypt=True.

  • Instant File Initialization está habilitado para NT Service\MSSQLSERVER. No se requiere acción; IFI no se aplica a archivos de registro.

Bloqueos e interbloqueos

Se detectaron 2 interbloqueos en los últimos 7 días. La información no contiene el XML completo ni identifica de forma legible las bases, objetos, propietarios de locks o víctimas, por lo que no es seguro atribuirlos a una tabla concreta.

La sesión 101 tiene un lock PAGE, uno OBJECT y uno KEY; las sesiones 72, 74, 75, 98, 100, 101 y 109 tienen locks DATABASE. Estos conteos son pequeños en la instantánea. La espera LCK_M_S acumuló 995,64 minutos y requiere correlación temporal.

  • Ejecutar análisis detallado con el objetivo “Fix Deadlocks”.
  • Uniformar el orden de acceso a tablas, mantener transacciones cortas y asegurar índices sobre predicados de búsqueda y claves foráneas.
  • Revisar consultas que usen ROWLOCK, deshabiliten locks de página/fila o escaneen tablas grandes. No se proporcionaron consultas de usuario con esas características, por lo que no se puede señalar una sentencia concreta.
  • Considerar READ_COMMITTED_SNAPSHOT solo tras evaluar tempdb, semántica de aplicación y carga de versiones; algunas bases ya tienen RCSI activado y otras no.

Scripts de apoyo (no forman parte del cambio)

Revisar la configuración actual de memoria, Query Store, archivos y recuperación

Este script es diagnóstico y no cambia la configuración.

USE [master];
GO
SELECT
    name AS configuration_name,
    value AS current_value,
    value_in_use AS running_value
FROM sys.configurations
WHERE name IN
(
    N'max server memory (MB)',
    N'min server memory (MB)',
    N'cost threshold for parallelism',
    N'max degree of parallelism',
    N'optimize for ad hoc workloads',
    N'backup checksum default',
    N'backup compression default'
)
ORDER BY name;
GO

SELECT
    name,
    state_desc,
    recovery_model_desc,
    compatibility_level,
    is_auto_close_on,
    is_auto_shrink_on,
    is_auto_create_stats_on,
    is_auto_update_stats_on,
    is_read_only
FROM sys.databases
ORDER BY name;
GO

SELECT
    DB_NAME(database_id) AS database_name,
    name AS file_logical_name,
    type_desc,
    size * 8.0 / 1024 AS size_mb,
